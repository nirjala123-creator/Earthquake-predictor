**Earthquake Magnitude Prediction and Classification using Machine Learning
Project Overview**

This project analyzes historical earthquake data to predict earthquake magnitude and classify earthquakes into severity categories using machine learning techniques. The workflow includes data preprocessing, feature engineering, exploratory data analysis, model training, evaluation, and visualization.

Key Features:
Cleaned and preprocessed real-world earthquake datasets
Handled missing values and encoded categorical variables
Extracted temporal features from date and time attributes
Performed exploratory data analysis and visualization
Built regression models for magnitude prediction
Compared Linear Regression, Random Forest, Gradient Boosting, Extra Trees, and XGBoost
Developed a classification model to categorize earthquakes into Low, Moderate, and High severity
Analyzed feature importance to identify key factors affecting earthquake magnitude
